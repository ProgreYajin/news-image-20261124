A newspaper front page summing up 24 November 2026's world news in one image: Nvidia brings back Jensen Huang, Kyiv strikes, an Indonesia factory fire, the Grok lawsuit, COP31, an India-Nepal train story, and a Thanksgiving storm.

Entry for make.fun's ["Sum up 24 November's world news in one image"](https://make.fun/bounty/news-image-20261124) bounty ($100 in USDC). `main.ts` copies the pre-rendered `entry.png` (drawn by `draw.py`) to the output directory and verifies the copy byte-size.
